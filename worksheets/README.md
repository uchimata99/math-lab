# דפי עבודה מודפסים — מעבדת המספרים

חוברות תרגול להדפסה (A4, עברית מנוקדת, RTL) בסגנון "מעבדת המספרים":
6 כרטיסים אווריריים לעמוד, מספר בעיגול, תיבת עבודה, ומפתח פתרונות נפרד.

## מבנה
- `scripts/` — מחוללי הדפים (Node.js, ללא תלויות). כל סקריפט כותב קובצי HTML לתיקייה שלו.
- `pdf/` — החוברות המוכנות (PDF):
  - `grade5-6-core.pdf` — כיתות ה'–ו', רמה 1: שברים · חזקות · פירוק לגורמים · משוואות + מפתח.
  - `equations-ladder.pdf` — משוואות בנעלם, רמות 1→4 (תרגילים בלבד, 12 עמ').
  - `equations-answers.pdf` — מפתח פתרונות למשוואות (רמות 2–4).
  - `advanced-L3.pdf` — רמה 3 מתקדמת: חזקות · פירוק לגורמים · שברים (6 עמ', ללא מפתח).
  - `advanced-L3-answers.pdf` — מפתח פתרונות לרמה 3 המתקדמת.
  - `grade2-booklet.pdf` — כיתה ב', 12 עמ': עד 10 · עד 20 · עשרות · עשרות מעל 100 · עד 100 · כפל 1–5, שני עמודים לכל נושא (תרגילים בלבד, ללא מפתח).

## כללים שנשמרים בתוכן
- כל התשובות מחושבות בקוד (המפתח תמיד נכון), ותרגילים ייחודיים ללא כפילויות.
- משוואות: בלי סימני `×` ו-`:` — כותבים `5x`, וחילוק כשבר (`x/3`).
- פירוק לגורמים: התשובות עם חזקות (לדוגמה `18 = 2×3²`).
- עברית מנוקדת; ביטויים מתמטיים מבודדים כ-LTR למניעת היפוך.

## איך מפיקים מחדש
דורש Node.js ודפדפן Chromium (להמרת HTML→PDF). לדוגמה:

```bash
cd scripts
node 02_grade2_booklet.js          # כותב קובצי g2-*.html באותה תיקייה
# להמרה ל-PDF (דוגמה עם chromium headless):
chromium --headless --no-pdf-header-footer --print-to-pdf=out.pdf file://$PWD/g2-01a-add10.html
```

הרמות של המשוואות:
1. חד-שלבי (`5x = 20`) + מערכת `x+y`/`x−y`.
2. דו-שלבי (`2x + 3 = 11`) + מערכת עם מקדם אחד.
3. נעלם משני הצדדים (`2x + 1 = x + 7`) + מערכות עם שני מקדמים.
4. סוגריים (`2(x+3) = 16`) + מערכות שדורשות הכפלה.
